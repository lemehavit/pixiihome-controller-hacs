# Security

Only the latest published version is maintained. This beta has not had an
independent security audit. Use the simulator or monitoring before enabling
physical control.

Report vulnerabilities using GitHub's **Security → Report a vulnerability** for
this repository. If private reporting is unavailable, open an issue asking the
maintainer to enable a private channel, without publishing exploit details or
installation information. Do not post tokens, passwords, private keys, raw
journals, HAR captures or identifiable telemetry in a public issue.

Provide the affected version, a minimal anonymized reproduction, impact and any
proposed mitigation. No response-time or fix-time guarantee is offered.
